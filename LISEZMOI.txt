LA FORGE DES BRUMES — appli installable
=======================================

Ce dossier contient le jeu complet sous forme d'appli web installable :
index.html (le jeu), manifest.webmanifest (nom, icône, plein écran),
sw.js (fonctionnement hors connexion) et les icônes.

Pour qu'un téléphone puisse l'installer, le dossier doit être servi en HTTPS.
Deux façons gratuites de le mettre en ligne :

1) GitHub Pages
   - Créez un dépôt sur github.com, déposez-y le contenu de ce dossier
     (bouton « Add file » > « Upload files »).
   - Settings > Pages > Source : « Deploy from a branch », branche main, dossier / (root).
   - Après une minute, le jeu est en ligne à l'adresse https://VOTRE-NOM.github.io/NOM-DU-DEPOT/

2) Netlify
   - Sur app.netlify.com/drop, glissez-déposez ce dossier entier.
   - Netlify donne une adresse https://….netlify.app

Installer ensuite sur le téléphone :
   - iPhone : ouvrez l'adresse dans Safari > bouton Partager > « Sur l'écran d'accueil ».
   - Android : ouvrez l'adresse dans Chrome > menu ⋮ > « Installer l'application ».
   - Ordinateur : Chrome ou Edge > icône d'installation dans la barre d'adresse.

Le jeu s'ouvre alors en plein écran depuis son icône et marche hors connexion.
La sauvegarde est stockée sur l'appareil (une par appareil et par navigateur).
Pour une mise à jour, remplacez simplement les fichiers en ligne : l'appli
récupère la nouvelle version à la prochaine ouverture avec connexion.
